# NAU_EIE 南京农业大学电子信息专业
**适用对象**：南京农业大学电子信息专业本科生（大一大二优先），转专业、辅修、跨考同学同样可以参考
**维护状态**：已确认在**2030**年前保持更新（注意：政策性更新可能滞后。原因见 [政策性更新](#政策性更新)）
**怎么参与**：发现问题请提 Issue，有经验请提 PR，见 [如何贡献](#如何贡献)

---

## 仓库定位

这个仓库**是**：

- 一份经验型攻略：什么时候该做什么、哪些坑可以绕开
- 一份资料索引：课程笔记、书单、网站、工具、模板
- 一个可以提问的地方：开 Issue 问，比在群里问更容易被后来人搜到

这个仓库**不是**：

- 官方信息渠道。培养方案、保研细则、学分认定、转专业条件一律以教务处和学院当年发布的文件为准，本仓库只做索引和转述
- 课件和教材的存放地。不上传老师课件、盗版电子书、未授权软件
- 唯一答案。经验都有主观性，写清依据比下结论重要

## 如何提问

在哪问：课程问题先问助教和老师；方向和经验问题可以直接在本仓库开 Issue，写清楚的问题会被后来人搜到，等于帮了下一届。

提问模板：

```text
【环境】Windows 11 / Keil 5.38 / STM32F103C8T6
【目标】想实现按键中断点亮 LED
【现象/报错】下载后灯不亮，串口打印停在 XXX（附完整报错文字或截图）
【已尝试】换过板子、重装过驱动、对照过例程第 X 行
【查过的资料】XX 教程第 X 节、YY 视频第 X 分钟
```

别做的事：只发一句“有人吗”、只贴截图不贴文字、报错只截一半、“在线等挺急的”。

## 如何贡献

1. Fork 本仓库，新建分支（如 `docs/dianSai-experience`）
2. 按 [仓库结构](#仓库结构) 放到对应目录，文件名用中文全称，避免歧义
3. PR 描述写清三件事：改了什么、依据是什么、核实日期

内容要求：

- 写具体经验，不写空话。与其写“模电很难”，不如写“第 X 章 XX 定理建议配合仿真，考试常考 XX 题型”
- 涉及政策、数据、时间节点，必须附官方链接和查询日期
- 一个 PR 只做一件事，方便 review
- 署名自愿，默认记入致谢

禁止提交：

- 老师课件、盗版教材和软件、未授权的真题
- 他人隐私（学号、手机号、成绩单截图）
- 未经核实的传言和“听说保研要 XX”
- 广告和拉群二维码

发现错误怎么办：直接提 Issue，标题写清「哪一节 + 什么问题」，附上依据链接，维护者会尽快改。
